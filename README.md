# Модуль подбора и расчёта стоимости туристических пакетов

Программный модуль для автоматизации работы туристического агентства.

## Возможности
- Поиск туров по направлению и датам
- Расчёт стоимости с учётом питания, типа номера и сезона
- Учёт дополнительных услуг (страховка, трансфер, экскурсии)
- Скидка за раннее бронирование

## Запуск
```bash
python main.py
